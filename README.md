# Proposta comercial - Tsuki x Arcano Digital

Apresentacao imersiva em 14 slides, com a identidade visual do Tsuki (preto, dourado e vermelho).

## Como apresentar

1. Abra `index.html` no navegador (Chrome ou Edge).
2. Use **tela cheia** (`F` ou o icone no canto).
3. Navegue com:
   - roda do mouse / trackpad
   - setas do teclado
   - toque (swipe) no celular
   - pontos a direita da tela
